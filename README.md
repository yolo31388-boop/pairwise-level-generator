# 游戏内程序化关卡生成与难度曲线系统

## 项目描述

游戏内程序化关卡生成与难度曲线系统的bug修复项目。核心模块 `level/generator.py` 存在多个已知bug，需要修复后使测试全部通过。

## 已知问题

- 关卡生成完全没做关卡都是固定的
- 难度曲线完全没做难度永远一样
- 关卡设计完全没做关卡没有设计原则
- 玩家体验完全没做不知道玩家体验好不好
- 自适应难度完全没做不能根据玩家水平调整
